# Правила проекта Heat Map · BR

## ⛔ Базовая карта — ТОЛЬКО 2ГИС. НИКОГДА не менять.

Подложка карты в `app.js` — плитки **2ГИС**
(`https://tile{s}.maps.2gis.com/tiles?x={x}&y={y}&z={z}&v=1`).

Это окончательное решение владельца. **Запрещено** менять её на CARTO, OSM,
Mapbox или любую другую — даже при редизайнах, даже если референс/скриншот
показывает другую подложку. Меняется только по прямой явной просьбе владельца
именно про подложку карты.

## Прочее

- Полный контекст проекта — в `CONTEXT.md` (архитектура, модель данных,
  договорённости). Прочитать перед работой.
- При любом изменении `app.js` / `style.css` / boot-скрипта — поднять версию
  кэша `?v=YYYYMMDD<буква>` в `index.html` (оба места: style.css и app.js).
- Дизайн-токены — только из `:root` в `style.css`, новые цвета не вводить.
- Перед коммитом: `node --check app.js`.
