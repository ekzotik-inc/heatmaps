# Субагенты проекта

Набор специализированных агентов Claude Code. Формат — стандартный
(`---`-фронтматтер с `name` / `description` / `model`, дальше системный промпт),
структура промптов собрана по практикам публичных коллекций субагентов на
GitHub (роль → рамки проекта → чек-лист → формат ответа) и адаптирована под
этот репозиторий: ванильный JS без сборки, Leaflet + 2ГИС, Express на Render.

| Агент | Когда вызывать |
|-------|----------------|
| `senior-engineer` | Сложные многошаговые задачи, архитектура, техдолг |
| `code-reviewer` | После правок, до коммита: регрессии, XSS, инварианты состояния |
| `security-auditor` | Перед релизом, при правках `server/`, `render.yaml`, CI |
| `frontend-ux` | Изменения интерфейса, доступность, адаптив |
| `performance-optimizer` | Тормоза, рост объёма данных, тяжёлые пересчёты |
| `geo-analyst` | Формулы тепла/рекомендаций, новые города и страны |
| `docs-keeper` | Документация разошлась с кодом |

## Как вызвать

```
> используй агента code-reviewer для проверки последних правок
```

или из кода — через инструмент `Agent` с `subagent_type: "code-reviewer"`.

Агенты видят те же правила, что и основная сессия (`CLAUDE.md`), — в частности
запрет на смену подложки карты и обязательный бамп версии кэша.
