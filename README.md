# Heat Map · BR

Аналитический инструмент для сети BR — визуализация спроса на сигареты и стики по городам Узбекистана, анализ покрытия торговыми точками и формирование адресных программ.

---

## Как запустить

Приложение работает в браузере, сервер нужен только для командной синхронизации.

```
Фронтенд:  открыть index.html (или GitHub Pages)
Сервер:    cd server && npm install && node server.js
```

Без сервера приложение полностью работает — все настройки хранятся в браузере локально.

---

## Вход и режим работы

При открытии появляется экран авторизации. После входа нужно выбрать режим:

**Просмотр** — все действия сохраняются только у тебя в браузере. Не влияет на то, что видят коллеги.

**Редактирование** — каждое изменение автоматически отправляется на сервер. Все участники видят актуальную картину в реальном времени.

Режим фиксируется до следующего входа. Значок в правом верхнем углу карты всегда показывает текущий режим и статус синхронизации.

## Разделы боковой панели

Панель разбита на 8 разделов-аккордеонов. Кликни на заголовок — раздел открывается.

---

### 1. Город

Выбор города для фильтрации данных. Все тепловые слои, точки сети и рекомендации обновляются под выбранный город. «Все» — показывает данные по всему Узбекистану.

---

### 2. Тепловые слои

Визуализация спроса на карте в виде цветовых пятен.

**Встроенные слои:**
- **Сигареты** — тёплая красно-жёлтая палитра
- **Стики** — холодная синяя палитра

Оба слоя можно показывать одновременно — они накладываются через режим смешения, зоны пересечения видны сразу.

**Настройки каждого слоя:**
- Включить / выключить
- Палитра: 6 научных цветовых схем (YlOrRd, Blues, Viridis, Inferno, Magma, Turbo) или свой цвет
- Интенсивность — насколько ярко рисуются пятна
- Прозрачность

**Общие настройки тепла:**
- Яркость — общий множитель для всех слоёв
- Размер пятна — радиус одной точки в пикселях
- Режим наложения слоёв (multiply, screen, overlay и др.)

**Свои слои:** через кнопку «+ Слой» можно создать пустой слой и загрузить в него данные из Excel/CSV. Файл должен содержать колонки `name`, `lat`, `lon`, `value`.

---

### 3. Точки сети

Все торговые точки BR и IQOS на карте. Каждая точка — маркер, тип различается цветом и формой.

**Настройки:** для каждого типа точек можно изменить цвет маркера и иконку.

---

### 4. Свои точки

Пользовательские наборы маркеров — например, список точек Re-traffic, конкурентов или любых других адресов.

**Как добавить слой:**
1. Нажать «+ Слой», ввести название и цвет
2. Нажать «Загрузить данные» → выбрать CSV или XLSX
3. Файл должен содержать колонки: `name`, `lat`, `lon`. Опционально: `addr` (адрес), `code` (код точки)

Каждый слой можно включить/выключить, перекрасить или удалить.

---

### 5. Рекомендации

Алгоритм автоматически находит зоны с высоким спросом, где ещё нет торговых точек сети.

**Настройки:**
- **Основа расчёта** — по сигаретам, стикам или обоим
- **Радиус покрытия** — зона вокруг каждой существующей точки, которая считается «покрытой»
- **Количество зон** — сколько рекомендаций показать

Рекомендации показываются на карте пронумерованными маркерами. Клик по маркеру открывает карточку с деталями — спрос в зоне, ближайшая точка, объём вне покрытия.

Список рекомендаций можно экспортировать в Excel.

---

### 6. Адресная программа

Инструмент для формирования списков точек с заданными условиями по расстоянию.

**Работает в 4 шага:**

**Шаг 1 — Что анализируем?**
Выбери источник точек:
- Отгрузки (сигареты + стики) — точки из данных об отгрузках
- Сигареты или Стики отдельно
- Любой загруженный слой «Свои точки» (например, Re-traffic)

**Шаг 2 — Расстояние до**
Выбери ориентир (BR/IQOS или любой загруженный слой) и задай условие:
- Оператор: ≤ ≥ < >
- Расстояние: ползунок от 200 м до 10 км

Пример: *Re-traffic, расстояние до BR/IQOS ≥ 3 км* — покажет точки Re-traffic, которые работают слишком далеко от наших магазинов.

**Шаг 3 — Объём точки** *(только для отгрузок и тепловых слоёв)*
Фильтр по объёму: оператор + «среднего по выборке» или конкретное число.

**Шаг 4 — Исключить точки** *(только для режима Отгрузки)*
Убрать из результата точки, которые уже рядом с выбранными слоями (например, рядом с Re-traffic). Задаётся расстояние и оператор.

**Кнопки:**
- **На карте** — показывает оранжевые маркеры (результат) + синие маркеры (ориентиры) + пунктирные линии от каждой точки к ближайшему ориентиру. Клик по оранжевому маркеру — попап с расстоянием до конкретного ориентира.
- **Excel** — выгружает список с координатами, объёмом и расстоянием до ориентира. Второй лист — параметры фильтра.

---

### 7. Доход Ташкента

Тепловая карта доходов населения по микрорайонам Ташкента.

- Тепловая карта — интенсивность цвета = уровень дохода
- Ядра (метки 1–15) — центры микрорайонов с цифровым рейтингом
- Границы районов — контуры 12 административных районов
- Цветовая схема: 3 уровня (высокий / средний / ниже среднего), цвет каждого настраивается

---

### 8. Данные и настройки

**Загрузка данных по шаблону:**
Скачай шаблон Excel, заполни по образцу (name, lat, lon, value) и загрузи в нужный тепловой слой. Карта обновится сразу.

**Поделиться настройками:**
- Экспорт — сохраняет все текущие настройки в JSON-файл
- Импорт — загружает настройки из файла

Это удобно для работы без сервера или передачи конкретной конфигурации коллегам.

---

## Командная синхронизация

Когда сервер подключён, приложение автоматически:
- При открытии страницы загружает последнее сохранённое состояние с сервера
- В режиме «Редактирование» отправляет каждое изменение на сервер через несколько секунд после действия
- Показывает индикатор синхронизации: зелёный — всё актуально, красный — ошибка связи

Если сервер недоступен, все изменения остаются в браузере и применятся при следующем подключении.

## Файлы для загрузки данных

### Тепловые слои (отгрузки)

| Колонка | Обязательная | Описание |
|---------|-------------|----------|
| `name` / `назв` | — | Название точки |
| `lat` / `широт` | ✓ | Широта |
| `lon` / `долгот` | ✓ | Долгота |
| `value` / `объ` / `vol` | — | Объём (по умолчанию 1) |

### Свои точки (маркеры)

| Колонка | Описание |
|---------|----------|
| `name` | Название |
| `lat`, `lon` | Координаты |
| `addr` | Адрес |
| `code` | Код точки (для дедупликации при исключениях) |

Русские названия колонок тоже распознаются автоматически.

## Структура проекта

```
heatmaps/
├── index.html     — разметка страницы
├── style.css      — все стили
├── app.js         — логика карты, фильтров, синхронизации
├── data.js        — встроенные данные (точки сети, отгрузки, районы, доходы)
└── server/
    ├── server.js  — Node.js/Express сервер синхронизации
    ├── .env       — конфигурация (PORT, API_KEY, ALLOWED_ORIGINS)
    └── state.json — хранилище общего состояния (создаётся автоматически)
```
