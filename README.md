# 🗺️ Heat Map · BR

**Интерактивная карта-аналитика спроса для сети торговых точек BR.**

Приложение визуализирует спрос на сигареты и стики в городах Узбекистана,
накладывает данные о доходах населения и автоматически подсказывает,
где выгоднее всего открыть новую торговую точку.

---

## 🎯 Что делает проект

Команда видит одну общую живую карту: данные и настройки синхронизируются
между всеми участниками автоматически. Один человек обновил данные — все
сразу видят актуальную картину.

---

## ✨ Возможности

### 🔥 Тепловые слои спроса
- Независимые слои **«Сигареты»** и **«Стики»** — можно смотреть по отдельности или вместе.
- При наложении слои **смешиваются**: зоны пересечения спроса видны сразу.
- 6 научных цветовых палитр (Viridis, Inferno, Turbo и др.) + свой цвет для каждого слоя.
- Настройка яркости, прозрачности, размера пятна и режима наложения.
- Можно **создавать собственные слои** и загружать в них свои данные из Excel.

### 📍 Рекомендации «где открыть ТТ»
- Алгоритм находит зоны **высокого спроса вне покрытия** существующих точек.
- Основа расчёта на выбор: сигареты, стики или сумма.
- Регулируемый радиус покрытия действующих точек и количество зон.
- Клик по рекомендации — перелёт камеры и подробная карточка зоны.
- Экспорт рекомендаций в **Excel** для отчётов.

### 🏪 Действующие точки
- Все точки сети на карте, типы различаются цветом и формой маркеров.
- Фильтрация по городам.

### 💰 Доход населения (Ташкент)
- Тепловая карта дохода и ядра дохода по микрорайонам.
- Границы 12 районов города.
- Настраиваемая цветовая схема уровней дохода.

### 📊 Свои данные
- Загрузка данных по **готовому шаблону Excel/CSV** — колонки распознаются
  автоматически, в том числе русские названия.
- Перетащил файл — карта обновилась.

### 👥 Командная работа
- **Общее состояние карты**: настройки и данные синхронизируются через сервер —
  вся команда видит одно и то же.
- Два режима работы: **«Просто посмотреть»** (личные эксперименты, не влияют
  на общую карту) и **«Редактировать»** (изменения видны всем).
- Индикатор синхронизации показывает, актуальны ли данные.
- Экспорт/импорт настроек файлом — на случай работы без сети.

## 🛠️ Технологии

| Компонент | Что используется |
|-----------|------------------|
| Карта | [Leaflet](https://leafletjs.com/) + [Leaflet.heat](https://github.com/Leaflet/Leaflet.heat) |
| Подложка | CARTO Voyager |
| Excel / CSV | [SheetJS](https://sheetjs.com/), [PapaParse](https://www.papaparse.com/) |
| Фронтенд | Чистые HTML / CSS / JS — без сборки |
| Бэкенд | Node.js + Express (синхронизация состояния команды) |

## 📝 Примечания

- Микро-слой дохода относится к **Ташкенту**; координаты ядер — приближённые
  центры зон, классификация — по предоставленным данным.
- Рекомендации носят аналитический характер и зависят от выбранной основы
  расчёта и параметров покрытия.
