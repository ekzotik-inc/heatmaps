# 🗺️ Тепловая карта · Сигареты + Стики · Рекомендации BR

Интерактивная веб-аналитика для визуализации спроса и подбора локаций под новые
торговые точки (ТТ) сети **BR**. Приложение строит тепловые карты по слоям
«Сигареты» и «Стики», накладывает данные о доходах по районам Ташкента и
автоматически рекомендует зоны, где выгоднее всего открыть новую точку.

Всё работает в одном файле `index.html` — без сборки, сервера и зависимостей,
кроме CDN-библиотек. Достаточно открыть файл в браузере.

---

## ✨ Возможности

### Тепловые слои
- Независимые слои **Сигареты** и **Стики** — можно включить оба одновременно.
- Настройка **цвета** и **интенсивности** каждого слоя.
- **Общая яркость тепла** — единый ползунок, масштабирующий все слои сразу.
- **Создание собственных слоёв** и загрузка в них данных по шаблону.

### Рекомендации «где открыть ТТ BR»
- Автоподбор зон с высоким спросом **вне зоны покрытия** существующих точек.
- Основа расчёта: сигареты / стики / сумма.
- Регулируемый **радиус покрытия** действующих ТТ и **число зон**.
- Топ-3 всегда на виду, остальные — раскрываются по кнопке.
- Клик по зоне — перелёт камеры и подробная карточка.
- **Экспорт рекомендаций в Excel** (.xlsx) для отчётов.

### Точки IQOS
- Маркеры **BR** и **IP with 2nd SE** различаются цветом и формой.
- Современные иконки: капля, гексагон, маяк, щит и др.

### Микро-уровень дохода (Ташкент)
- Тепловая карта дохода, ядра дохода (метки 1–15), границы 12 районов.
- Настраиваемые цвета уровней: высокий / средний / растущий.

### Данные и состояние
- Загрузка данных по **шаблону Excel/CSV** (с автоопределением колонок).
- **Автосохранение** всех настроек и пользовательских данных в `localStorage` —
  работа не теряется при перезагрузке.
- Фильтр по городам.
- Экран входа с авторизацией.

## 🚀 Запуск

Локально:

```bash
# просто откройте файл в браузере
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

Или через любой статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Через **GitHub Pages**: в настройках репозитория включите Pages с ветки `main`,
после чего сайт будет доступен по адресу
`https://<пользователь>.github.io/heatmaps/`.

> ⚠️ Это клиентская «защита от случайных глаз»: учётные данные хранятся в коде и
> видны в исходнике. Для реальной защиты публичного сайта используйте серверную
> аутентификацию.

## 📥 Загрузка собственных данных

1. Нажмите **«⬇ Скачать шаблон (Excel)»** — скачается `.xlsx` с нужными колонками.
2. Заполните строки. Поддерживаемые колонки (регистр и язык не важны):

   | Колонка  | Назначение                  | Пример          |
   |----------|-----------------------------|-----------------|
   | `name`   | Название точки/зоны          | `Пример ТТ`     |
   | `lat`    | Широта                       | `41.311100`     |
   | `lon`    | Долгота                      | `69.279700`     |
   | `value`  | Объём / спрос                | `12.5`          |

   Распознаются и русские варианты заголовков (`широта`, `долгота`, `объём`,
   `название` и т.п.), а также `lng`, `amount`, `итог`.
3. Выберите целевой слой (или создайте новый кнопкой **«+ Создать новый слой»**).
4. Перетащите/выберите файл и нажмите **«Обновить карту»**.

Поддерживаются форматы **`.xlsx`, `.xls`, `.csv`**.

## 📂 Структура

```
heatmaps/
├── index.html   # всё приложение: разметка, стили и логика
└── README.md
```

Внутри `index.html`:
- **`<style>`** — оформление интерфейса и карты.
- **`DATA`** — встроенный набор: точки сети, данные по слоям, ядра дохода, границы районов.
- **`<script>`** — логика карты, рекомендаций, загрузки данных, авторизации и сохранения состояния.

---

## 💾 Хранение данных

Все настройки и пользовательские слои сохраняются в `localStorage` браузера
(ключ `hm_state_v1`). Чтобы сбросить состояние — очистите данные сайта в браузере.
Авторизация хранится в `sessionStorage` и сбрасывается при закрытии вкладки или
кнопкой **«Выйти»**.

## 📝 Примечания

- Микро-слой дохода относится к **Ташкенту**; координаты ядер — приближённые
  центры названных зон, классификация — по предоставленным данным.
- Рекомендации носят аналитический характер и зависят от выбранной основы и
  параметров покрытия.
